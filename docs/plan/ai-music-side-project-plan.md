## 0. 핵심 요약 (One-Pager)

**무엇을**: 한국어 콘텐츠 크리에이터(유튜버, 팟캐스터, 인디 게임 개발자)를 위한 AI BGM 생성 SaaS

**왜**: Suno는 한국어 UI·결제·법적 안전 인증을 제공 안 함. 좁은 한국 vertical에서 wedge 확보 가능.

**어떻게**: ACE-Step 1.5 (Apache 2.0, 오픈소스) + Replicate API 호스팅 + Next.js + Supabase. 솔로 운영.

**얼마나**: 12개월 후 현실적 목표 월 매출 300~500만 원 (유료 사용자 300~500명). 실패 시 매몰비용 한 자릿수 백만 원 + 3개월 시간.

**언제**: M1~M3 MVP 빌드 및 베타 출시 → M4~M6 PMF 검증 → M7~M12 확장 또는 정리

**왜 사이드 프로젝트인가**: 본업(빅밸류) 유지하며 학습·포트폴리오·소액 매출 동시 추구. 망해도 자산(코드·도메인 학습·콘텐츠) 잔존. PMF 검증되면 풀타임 전환 검토.

## 1. 시장 분석 핵심 요약

### 1.1 시장 구조 (2026.05 현재)

- 글로벌 AI 음악 시장 CAGR 20~28% (보고서별 차이)
- Suno가 카테고리 절대강자: ARR $300M, 100M+ 사용자, $5B valuation 진행 중
- 법적 환경 대전환: 2025년 말 UMG-Udio, Warner-Suno 합의 → 라이선싱 시대 진입
- Sony와 UMG는 Suno와 계속 소송 중. 2026년 7월 핵심 판결.
- 오픈소스의 Stable Diffusion 모먼트: ACE-Step 1.5 (2026.01) — Apache 2.0, 풀송 가능, 로컬 실행
- 한국 시장은 비어있음 (KOMCA·문체부 규제 미정, 한국어 가창 데이터 부족)

### 1.2 진입 시나리오 평가

| 시나리오 | 솔로 가능성 | 12개월 매출 (현실적) | 결론 |
|---------|------------|---------------------|------|
| Suno 정면 카피 | 어려움 | 0~200만 원 | 자살. 포기 |
| **한국 크리에이터 자가서비스 SaaS (옵션 A)** | **가능** | **300~800만 원** | **선택** |
| 개발자 API | 가능 | 100~500만 원 | 후순위 |
| 오픈소스 + 호스팅 | 가능 | 0~300만 원 | 후순위 |
| 광고대행사 B2B | 솔로 불가 | — | 공동창업자 합류 시 |
| 컨설팅 + 도구 | 가능 | 1,000~3,000만 원 | 풀타임 전환 시 검토 |

### 1.3 솔로 + 오픈소스의 구조적 제약

- GPU 비용: 자체 호스팅 시 사용자 0명이어도 월 70만 원~ 적자. **Replicate API 사용으로 우회**.
- 데이터 라이선스: 한국 인디 레이블·KOMCA와 라이선스 계약 솔로 불가능. **컴플라이언스 wedge 포기**.
- B2B 세일즈: 대면 미팅·법무 응대·SLA 솔로 불가능. **B2C 자가서비스로 한정**.
- 핑거프린팅 DB: KOMCA 신탁곡 유사도 검사 불가능. **간이 인증서로 대체**.

## 2. 진입 전략: 옵션 A 자가서비스 SaaS

### 2.1 제품 콘셉트

> **"한국 콘텐츠 크리에이터가 자신의 영상·팟캐스트·게임에 쓸 BGM을 한국어 프롬프트로 30초 만에 생성하고, 저작권 안전 인증서와 함께 다운로드받는 도구."**

### 2.2 타겟 사용자 (ICP)

**1차 타겟 (Month 1~6)**:
- 한국어 유튜버 (구독자 1,000~100,000명)
- 특히: 브이로그, 먹방, 시사·교육, 게임, ASMR, 명상 채널
- 페인포인트: 무료 라이브러리는 식상, 유료는 비쌈, AI는 저작권 불안

**2차 타겟 (Month 6+)**:
- 한국어 팟캐스터 (인트로/아웃트로/스팟 음악)
- 인디 게임 개발자 (배경음, 메뉴 음악)
- 짧은 영상 크리에이터 (쇼츠/릴스/틱톡)

**의도적 제외**:
- 광고대행사 (B2B 솔로 불가)
- 음악학원 (다른 카테고리)
- 인디 아티스트 (Suno 직접 사용자, 가격경쟁 X)
- 글로벌 사용자 (한국 vertical 집중)

### 2.3 차별점 vs Suno

| 차원 | Suno | 본 프로젝트 |
|------|------|------------|
| UI 언어 | 영어 | 한국어 (네이티브) |
| 결제 | 해외 신용카드 | 토스페이먼츠 (한국 카드·계좌·간편결제) |
| 가격 | 월 $10 (~14,000원) | 월 9,900원 |
| 프롬프트 | 영어 권장 | 한국어 자연어 입력 (Claude로 변환) |
| 저작권 인증 | 없음 | 간이 인증서 PDF 자동 발급 |
| 한국어 가창 | 어색함 | 인스트루멘탈 집중 (Phase 2 가창) |
| DAW 통합 | Suno Studio | WAV 24-bit + MIDI export |
| 무료 한도 | 10곡/일 | 3곡/일 (덜 헤비) |
| 워크플로우 | 범용 | 유튜브 길이 프리셋 (15초/30초/60초/3분) |

**핵심**: Suno보다 좋을 필요 없음. **Suno가 한국 시장 신경 안 쓰는 공간**을 점유.

### 2.4 가격 정책

| 티어 | 월 가격 | 한도 |
|------|---------|------|
| Free | 0원 | 3곡/일, 워터마크 30초 미리듣기, 다운로드 X |
| Starter | 9,900원 | 30곡/월, 무제한 다운로드, WAV |
| Pro | 29,000원 | 무제한 생성, 스템 분리, MIDI export, 우선 큐 |
| Lifetime (얼리버드) | 290,000원 | 첫 100명 한정, Pro 평생 |

**Lifetime 얼리버드 추천 이유**: 초기 현금 흐름 + 충성 사용자 + 마케팅 무기. 100명 × 29만 원 = **2,900만 원 일시 매출 가능**.

## 3. 3개월 MVP 플랜 (Deep Dive)

### 3.1 전체 일정 개요

```
Month 1: Foundation + PoC + 디스커버리
├── Week 1-2: ACE-Step 한국어 PoC + 크리에이터 인터뷰 5건
├── Week 3-4: 기술 스택 셋업 + 단일 페이지 알파

Month 2: Core Product
├── Week 5-6: 결제 + 한도 + 인증서 + 워터마크

├── Week 11-12: 첫 유료 사용자 분석 + 다음 분기 계획
```

### 3.2 Month 1: Foundation + PoC

#### Week 1: 검증 (가장 중요한 주)

**목표**: 진입 전에 가장 위험한 가정을 검증한다.

**가장 위험한 가정 1**: ACE-Step 1.5가 한국 크리에이터 기준 "사용 가능한" 인스트루멘탈을 생성하는가?

**검증 방법**:
- Replicate에서 ACE-Step 1.5 API 호출 (계정 가입, $20 충전)
- 30개 프롬프트 테스트:
  - lo-fi 공부 음악, 브이로그 BGM, 게임 인트로, 명상 음악
  - K-drama 잔잔한 OST 스타일, 트로피컬 하우스, 시네마틱
  - 짧은 길이(15초·30초·60초), 긴 길이(2~3분)
- 각각 다운로드해서 본인 유튜브 영상에 깔아보고 "내가 쓸까?" 판단
- 결과를 5점 척도로 점수화 (3.5점 이상 = 진행, 미만 = 킬)

**가장 위험한 가정 2**: 한국 크리에이터가 이런 도구에 돈을 낼 의향이 있는가?

**검증 방법**:
- 디스코드·페이스북 그룹·트위터에서 크리에이터 5명 섭외
- 30분 비공식 인터뷰 (스크립트는 부록 참조)
- 질문 핵심:
  - 현재 어떤 BGM 소스를 쓰는가? (유튜브 오디오, Epidemic Sound, AIVA 등)
  - 매월 BGM에 얼마 쓰는가?
  - 저작권 클레임 받아본 적 있는가?
  - 한국어 프롬프트 AI BGM 도구가 있다면 월 얼마까지 낼 의향?

**Week 1 Go/No-Go 결정**:
- ACE-Step 품질 3.5/5 미만 → No-Go (다른 모델 검토하거나 프로젝트 킬)
- 크리에이터 5명 중 3명 이상 "월 9,900원이면 쓰겠다" 답변 → Go

#### Week 2: 경쟁 분석 + 디스커버리 심화

- 경쟁사 사용기 작성 (Suno, Udio, AIVA, Soundraw, Beatoven, ElevenLabs Music)
- 한국 크리에이터 인터뷰 추가 5건 (총 10건)
- 페이스북·유튜브 광고로 사용 중인 BGM 라이브러리 매핑
- 가격 민감도 검증: 토스페이먼츠 가입 + 9,900 / 19,900 / 29,000 가격 의사 조사

**산출물**:
- 인터뷰 노트 10건
- 경쟁사 비교표 v2
- 가격 의사결정 메모

#### Week 3: 기술 스택 셋업

```
프론트엔드:
- Next.js 15 (App Router)
- Tailwind CSS + shadcn/ui
- 한국어 UI

백엔드:
- Next.js API Routes (별도 백엔드 X)
- 인증: Supabase Auth (이메일 + Google OAuth)

데이터베이스:
- Supabase (PostgreSQL + Storage)
- 사용자, 생성 이력, 결제 이력 관리

음악 생성:
- Replicate API → ACE-Step 1.5 XL
- 폴백: YuE 7B (Replicate)
- 곡당 약 $0.10~0.30

프롬프트 변환:
- Claude API (Haiku 4.5 - 저렴, 빠름)
- 한국어 자연어 → ACE-Step 영문 프롬프트 변환

오디오 후처리:
- ffmpeg via Vercel Functions
- 워터마크 보이스 오버레이 (무료 사용자)
- 길이 자르기, 페이드 인/아웃, LUFS 정규화

결제:
- 토스페이먼츠 (한국 카드·계좌이체·간편결제)
- 또는 포트원 (구 아임포트, 정기결제 지원)

배포:
- Vercel (프론트 + API)
- Supabase (DB)
- CloudFlare R2 (음원 파일 저장 - S3보다 저렴)

이메일: Resend
분석: Posthog (무료 티어)
에러: Sentry (무료 티어)
```

**Week 3 산출물**:

### 3.3 Month 2: Core Product

**클로즈드 베타**:

- 베타 종료 시 설문조사 + 인터뷰
- 핵심 질문: NPS (0~10점) + "이대로 출시되면 월 9,900원 낼 의향?"

### 4.4 단위 경제 (Unit Economics)

**가정**: Pro 사용자 평균 월 50곡 생성 (헤비유저는 200곡까지)

| 항목 | Starter (9,900원) | Pro (29,000원) | Pro 헤비 |
|------|------------------|---------------|---------|
| 사용자 결제 | 9,900원 | 29,000원 | 29,000원 |
| 결제 수수료 (3%) | -297원 | -870원 | -870원 |
| Replicate (곡당 $0.20 가정) | 곡 30 × $0.20 ≈ -8,400원 | 곡 50 × $0.20 ≈ -14,000원 | 곡 200 × $0.20 ≈ -56,000원 |
| Claude API (곡당 $0.01) | -420원 | -700원 | -2,800원 |
| **Contribution margin** | **+783원** | **+13,430원** | **-30,670원** |
| 마진율 | 8% | 46% | -106% |

**핵심 인사이트**:
- Starter 티어는 거의 손해 (헤비 유저면 적자)
- **Pro 티어가 진짜 매출 견인** (마진 46%)
- 헤비 유저 비대칭 손실 → **무제한이 아닌 "월 200곡 한도" 정책 필요**
- Lifetime 290,000원은 약 10개월 만에 손익분기점

**고정비 회수**: 월 고정비 10만 원 → Starter 13명 또는 Pro 8명에 도달하면 흑자

**Worst case (PMF 실패)**:
- Month 6에 유료 30명 미만 → **킬 또는 피벗**
- 12개월 누적 매출 500만 원 이하
- 손실: 약 200~300만 원 (인프라 + 라이센스 비용)

**Base case (현실적)**:
- Month 12 MRR 약 300~500만 원
- 누적 매출 약 3,000~4,000만 원
- 본업 유지 사이드 프로젝트로 충분 (시간 대비 ROI는 평범)

**Best case (PMF 강함)**:
- Month 12 MRR 약 1,000만 원+
- 누적 매출 약 8,000만 원+
- 풀타임 전환 검토 가능

**Outlier case (드물게 발생)**:
- 한 콘텐츠가 바이럴 (유튜브·트위터)
- 한국 유명 유튜버가 사용 인증
- Month 6에 MRR 1,000만 원+ 점프

### 5.3 솔직한 기대치

**예상 확률**:
- Worst case: 40% (가장 흔한 결과)
- Base case: 40%
- Best case: 15%
- Outlier: 5%

**기댓값 (Expected MRR at M12)**:
- 40% × 100만 원 + 40% × 400만 원 + 15% × 1,000만 원 + 5% × 3,000만 원
- ≈ 40 + 160 + 150 + 150 = **약 500만 원**

**결론**: 사이드 프로젝트로 월 500만 원 기댓값. 빅밸류 본업 대체는 아직 안 됨. 본업 + 부수입 모델로 합리적.

## 6. Kill Criteria / Pivot Triggers

명확한 종료 조건을 미리 정해두지 않으면 매몰비용에 갇힌다.

### 6.1 명백한 Kill 조건

| 시점 | 조건 | 액션 |
|------|------|------|
| Week 1 말 | ACE-Step 1.5 한국 크리에이터 기준 품질 3.5/5 미만 | 프로젝트 종료 또는 다른 모델 검토 |
| Week 1 말 | 인터뷰 5명 중 3명 미만이 "월 9,900원 의향" | 가격 재설정 또는 다른 vertical |
| Week 8 말 | 베타 NPS < 30 | 한 달 내 큰 피벗 |
| Month 3 말 | 유료 사용자 5명 미만 | 마케팅 전략 전면 재검토 |
| Month 6 말 | 유료 사용자 30명 미만 | 프로젝트 종료 또는 큰 피벗 |
| Month 6 말 | CAC > LTV | unit economics 깨짐, 가격 재설정 또는 종료 |
| Month 9 말 | MRR < 100만 원 | 종료 검토 (시간 ROI 너무 낮음) |

### 6.2 외부 환경 Kill 조건

- Suno가 한국어 UI + 토스페이먼츠 정식 출시 → 차별점 즉시 소실
- KOMCA가 "AI 음악은 신탁 음악과 유사 시 무조건 침해" 가이드라인 발표 → 법적 리스크 증가
- ACE-Step 1.5가 라이선스 변경 또는 학습 데이터 문제 발견 → 모델 교체 또는 종료

### 6.3 Kill 시 자산 보존

프로젝트 종료해도 다음은 남는다:
- 코드 (오픈소스 공개 → 포트폴리오)
- 도메인·사용자 데이터 (다른 비즈니스로 활용)
- 클로드 코드·ACE-Step·결제·SaaS 운영 경험
- 학습 (시장·고객·기술)
- 블로그·유튜브 콘텐츠 (트래픽 잔존)

**Kill ≠ 실패**. 검증 결과 안 되는 시장임이 확인된 것.
